# v0.3｜Neuronal Morphology Viewer · 科学范围与设计说明

## 为什么替换原来的点线图

v0.2 的点代表人为生成的抽象节点，线表示最近邻关系；它适合作为联想概念画，但**没有树突、轴突、胞体，也没有实际生物形态数据**。v0.3 将形态数据与画面分离：可重建“父节点—子节点”的三维树结构，显示神经突起半径、局部投影深度与胞体位置。

## 可验证的数据接口

SWC 每个非注释行必须包含七列：`id type x y z radius parent`。类型通常含 `1` 胞体、`2` 轴突、`3` 基底树突、`4` 顶树突；不同数据库可能还含其他类型，渲染器保留其结构而不擅自判断细胞种类。

解析时拒绝重复 ID、无效数字、过大文件、零/负半径、缺失父节点和父链循环。支持最多 75,000 个节点与 5 MiB 的文本；渲染为二维画布上的三维透视投影。不同样本的绝对尺度会归一化，因此**不能从屏幕大小比较不同细胞的真实长度**。线宽与 SWC 半径保持单调关系，但由于性能与视觉最小线宽限制，精确比例在极端尺度下不成立。

用户选择的 SWC 使用浏览器 `File.text()` 直接读取；不通过 HTTP API、不写入 SQLite，也不会自动构建用户人格或记忆。软件无法自动证实样本的物种、脑区、实验来源、许可证、预处理方式和坐标单位。

## 内置程序化形态是什么

默认景象采用固定随机种子生成五个独立树突分枝细胞，其中主细胞有一个胞体、上伸的顶端树突、放射状基底树突和细长下行的轴突；其余细胞用于景深和尺度层次。形态参数是**视觉工程假设**，未拟合 NeuroMorpho / Allen 的树突长度分布、分支角、空间发育规律或实验统计。细胞间没有建模真实突触连接。

渲染基于 `CanvasRenderingContext2D`：把三维坐标按旋转矩阵和透视投影映射到二维，按深度排序绘制短线段与胞体。输出可交互，但不是 WebGL 三维体网格、不是脑组织数字孪生，也不证明出现生命或意识。

## 必须独立研究的三条科学线

| 研究方向 | v0.3 现状 | 下一验收门槛 |
|---|---|---|
| 神经解剖形态 | SWC 几何可视化（数据源用户手动提供） | 纳入带公开许可、物种/脑区/出版物/样本编号的真实重建；几何与参考查看器对照 |
| 神经电活动 | LIF 与简化 STDP 独立合成实验 | 真实电生理实验数据的参数拟合、时间单位与数值收敛验证 |
| 人的记忆与人格 | 经明确授权的文本来源库与人工审核 | 冻结标注集、时间归因和错记评测；禁止模型把推断默认为人格事实 |

## 科学引用与真实 SWC 的获取

1. Allen Institute for Brain Science. *Allen Cell Types Database*. Allen Institute. <https://alleninstitute.github.io/AllenSDK/cell_types.html>. 提供小鼠与人类细胞类型研究及可下载的形态 SWC；须逐样本确认物种与来源。
2. International Neuroinformatics Coordinating Facility. “SWC.” *INCF*. <https://incf.org/swc>. 描述 SWC 数据规范及其七列树结构。
3. NeuroMorpho.Org. “Terms of Use.” *NeuroMorpho.Org*. <https://neuromorpho.gmu.edu/useterm.jsp>. 数据按 CC BY 4.0 使用，须遵守原始文献和网站的署名要求；软件不自动抓取网站文件。

这些来源用于解释格式与未来真实数据路径，**不代表项目内置的程序化场景来自某一真实实验室**。
