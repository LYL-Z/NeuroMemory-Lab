# Phase 01+ / v0.3 初步验收记录

## 受测内容

仅使用完全虚构/合成文本、临时目录与本机 loopback 测试 HTTP 接口，没有导入任何真实个人资料，也没有调用云模型或访问外部知识平台。

运行命令：

```bash
python3 -B -m unittest discover -s tests -v
```

最新本地回归测试：**38 tests passed**，包括前端 SWC 解析、合成树形结构确定性、HTTP 静态资源和新增神经计算只读隔离检查。项目的 Windows/Linux GitHub Actions 远程矩阵仍需在本次代码发布后重新检查。

| 领域 | 验证 |
|---|---|
| 初始化 | 空数据库，审计链初始完整 |
| 授权导入 | 未明确同意时拒绝写入 |
| 来源 | SHA-256 与原始文本字符位置一致 |
| 检索 | 中文 3 字以上、短词、字面通配符和英文大小写区分 |
| 去重 | 相同内容不会建立第二个活动来源 |
| 撤销 | 内容从活动搜索和片段列表退出；原件仍在 |
| 候选记忆 | 来源关联、待审核、确认、二次改写受限 |
| 输入校验 | 非法扩展名、空文档、错误编码、大小限制 |
| 变更审计 | 修改历史记录可被检测出哈希不一致 |
| HTTP 安全 | 无令牌读写、非法 Host、恶意跨源写请求、缺授权拒绝 |
| UI | 本地页面包含会话令牌引用且不加载外部脚本 |
| LIF | 静息、不足阈值的稳态、超阈值发放、不应期及非法参数 |
| STDP | 脉冲时序正负方向、指数窗口与归一化权重边界 |
| Hopfield | 部分损坏线索恢复、能量非增、非法模式拒绝 |
| 科学隔离 | 神经演示接口仅处理合成数据，查询前后个人库为空 |
| 前端静态约束 | 神经形态及控件、仅本地脚本、降低动态效果设置、SWC 不联网 |
| SWC 结构 | 七列解析、树形分枝、重复节点、循环父链、未知父节点、非法半径 |

额外执行：`node --check neuromemory_cortex/ui/app.js` 与 `node --check neuromemory_cortex/ui/morphology.js` 通过（语法检验）；Node 测试用例验证固定种子生成的结构完全可复现。
